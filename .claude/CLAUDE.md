# CV Guillaume Sumann — GitHub Pages

## Contexte
Ce projet est un CV personnel hébergé sur GitHub Pages.
URL live : https://guillaumesumann-droid.github.io
Stack : index.html unique, tout CSS et JS inline, aucun framework.
Images dans le dossier racine.

## Règles absolues
- Ne JAMAIS supprimer ou modifier l'easter egg du footer
- Easter egg : cliquer 3 fois sur "N'appuyez surtout pas ici" → son Geiger + overlay ESR
- Après chaque modification : git add . && git commit -m "description" && git push
- Toujours tester localement (double-clic index.html) avant de pusher

## Design
- Light mode (défaut) : fond blanc #FFFFFF, texte #1D1D1F, accent #0071E3
- Dark mode : fond #000000, texte #F5F5F7, accent #2997FF
- Polices : Inter (body), JetBrains Mono (dates, codes)
- Style Apple : épuré, aéré, cinématique
